## Referencia para Unreal Engine 5

Epic Games recomienda para desarrollo en Windows:

- Windows 11.
- Procesador Intel o AMD de cuatro núcleos a 2.5 GHz o más.
- 32 GB de RAM.
- Tarjeta gráfica compatible con DirectX 12.
- 8 GB o más de VRAM.
- Controladores gráficos actualizados.

Consultar la fuente oficial antes de decidir: [Hardware and Software Specifications for Unreal Engine](https://dev.epicgames.com/documentation/unreal-engine/hardware-and-software-specifications-for-unreal-engine).

## Prueba mínima

Cuando ambas hayan revisado su equipo:

1. Instalar Epic Games Launcher y Unreal Engine solo si el equipo lo permite.
2. Abrir un proyecto vacío de tipo **First Person** usando Blueprints.
3. Crear una sala simple con piso, paredes, una luz y un objeto.
4. Ejecutar el proyecto y comprobar si ambas pueden abrirlo y navegarlo.
5. Registrar resultado, dificultad encontrada y evidencia.
