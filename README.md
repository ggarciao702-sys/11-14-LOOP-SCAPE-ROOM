
# LOOP -ESCAPE ROOM & LABERINTO 
--------------------------------------------------------------------------------------------
# DESCRIPCIÓN 
---------------------------------------------------------------------------------------------
Es una experiencia inmersiva en 3D de tipo "escape room" y laberintos donde tu mejor arma es la mente. A diferencia de las plataformas habituales de minijuegos,esta propuesta independiente combina acertijos de lógica compleja con escenarios que desafian tu percepción espacial.cada sala y pasillo está diseñado para poner a prueba tu capacidad de análisis,obligándote a observar los detalles más pequeños para descifrar los patrones ocultos.Si buscas un reto donde el pensamiento critico,la deducción,la estrategia y la adrenalina sean la única via para romper el ciclo y escapar "loop" está hecho para ti.
