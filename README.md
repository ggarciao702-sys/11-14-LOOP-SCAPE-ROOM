
# LOOP -ESCAPE ROOM & LABERINTO 
--------------------------------------------------------------------------------------------
# DESCRIPCIÓN 
---------------------------------------------------------------------------------------------
Es una experiencia inmersiva en 3D de tipo "escape room" y laberintos donde tu mejor arma es la mente. A diferencia de las plataformas habituales de minijuegos, esta propuesta independiente combina acertijos de lógica compleja con escenarios que desafían tu percepción espacial. Cada sala y pasillo está diseñado para poner a prueba tu capacidad de análisis, obligándote a observar los detalles más pequeños para descifrar los patrones ocultos. La experiencia se complementa con una plataforma web en JavaScript que incluye tienda de contenidos, ayuda con IA y soporte. Si buscas un reto donde el pensamiento crítico y la estrategia sean la clave para escapar, "LOOP" está hecho para ti.
